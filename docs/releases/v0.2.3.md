# Orbita R36S/H v0.2.3 — ArkOS ARM64

## Português brasileiro

**Já é possível jogar via Xbox Cloud Gaming no R36S/H com ArkOS.** Esta versão
experimental reúne login Microsoft, catálogo completo e streaming no portátil,
com busca de jogos por teclado na tela.

### Downloads

Em **Assets**, baixe **`orbita-r36sh-0.2.3.zip`**. O arquivo
`orbita-r36sh-0.2.3.zip.sha256` permite conferir a integridade do download.
Os arquivos automáticos **Source code** não são o aplicativo pronto.

O tutorial completo está no arquivo **`INSTALL.pt-BR.md`** desta release e
também dentro do ZIP, em `orbita/INSTALL.pt-BR.md`.

### Instalação rápida

1. Desligue o portátil e abra o cartão de jogos no computador.
2. Extraia o ZIP e copie **`Orbita.sh` e a pasta `orbita/`** para `EASYROMS/ports/`.
3. Ejete o cartão, recoloque-o no aparelho e conecte o ArkOS à internet.
4. Abra **Ports → Orbita**, autorize sua conta Microsoft pelo celular ou PC e
   escolha um jogo com **A**.

A pasta de ports no aparelho normalmente é `/roms/ports/` ou `/roms2/ports/`.
O pacote é para **Linux ARM64/ArkOS** e usa as bibliotecas do sistema. Não exige
conta no site Orbita nem chave beta.

### O que vem nesta versão

- Busca por nome com teclado na tela; ignora caixa, acentos, espaços e pontuação.
- Catálogo completo com nomes em cache e indicação separada de acesso pela conta.
- Sessão WebRTC, vídeo H.264 por software, áudio Opus e envio dos controles.
- Pedido padrão de vídeo de 720p/30 fps e limite de 1000 kbps.
- Tutorial de instalação e atualização em português e inglês dentro do pacote.

**Controles:** A joga; X busca; Start atualiza; Select localiza Fortnite.
Na partida, segure **Select + Start por 0,7 s** para voltar ao catálogo.

### Validação e limites

Uma sessão real de HOT WHEELS entregou vídeo 720p no portátil, com melhora de
fluidez relatada após o ajuste do decoder. A versão 0.2.3 passou nas sete suítes
ARM64 registradas na documentação; o último registro de instalação física é
da versão 0.2.2. A nova revisão ainda precisa de confirmação específica no aparelho.

Desempenho, som audível, todos os controles físicos, sincronização audiovisual e
recuperação de rede continuam em validação. O servidor determina o formato
recebido. O atalho Fortnite não concede acesso: a conta testada recebeu
`NoEntitlement` / `OfferingAccessDenied`, e a abertura não foi validada.

## English

**Xbox Cloud Gaming gameplay is already possible on the R36S/H running ArkOS.**
This experimental release combines Microsoft sign-in, the full catalog and
handheld streaming, with game search through an on-screen keyboard.

Under **Assets**, download **`orbita-r36sh-0.2.3.zip`** and optionally its
`.zip.sha256` file. The automatic **Source code** archives are not the application.
The full tutorial is attached as **`INSTALL.md`** and included as
`orbita/INSTALL.md` inside the ZIP.

### Quick installation

1. Turn the handheld off and open its games card on your computer.
2. Extract the ZIP and copy **`Orbita.sh` and `orbita/`** into `EASYROMS/ports/`.
3. Safely eject the card, put it back in the handheld and connect ArkOS to the internet.
4. Open **Ports → Orbita**, authorize your Microsoft account from a phone or PC,
   then select a game with **A**.

The device's ports directory is usually `/roms/ports/` or `/roms2/ports/`.
This is a **Linux ARM64/ArkOS** package using system libraries. No Orbita website
account or beta key is required.

This release includes normalized game search, cached catalog names, account
access indicators, WebRTC, software H.264 video, Opus audio and controller input.
The default video request is 720p/30 fps with a 1000 kbps limit.

**Controls:** A starts a game; X searches; Start refreshes; Select finds Fortnite.
During gameplay, hold **Select + Start for 0.7 s** to return to the catalog.

### Validation and limits

A real HOT WHEELS session delivered 720p video on the handheld, with smoother
play reported after a decoder adjustment. Version 0.2.3 passed the seven recorded
ARM64 test suites; the latest recorded physical-device installation is 0.2.2.
The new revision still needs specific on-device confirmation.

Performance, audible sound, all physical controls, audiovisual sync and network
recovery remain under validation. The server determines the received format.
The Fortnite shortcut does not grant access: the tested account received
`NoEntitlement` / `OfferingAccessDenied`, and launch remains unvalidated.
